# 查你家財位 2026 · @archsunneo

免費線上工具：用地圖／衛星影像對齊自家建築坐向，算 **24 山坐向** 與 **2026 流年九宮飛星八方位**，
最後導流到 Line 真人分析。純前端靜態，無後端、無帳號、無資料庫。

## 定位

對打 yiditu.tech，並中和對方「手機指南針不準」的攻擊——
我們不叫使用者拿手機量磁北，而是**從衛星影像量建築物本身的幾何角度**，不受鋼筋、家電、手機殼磁扣影響。

## 分享結果卡

結果區下方有「產生我的結果卡」，用純前端 canvas 畫一張 1080×1350 PNG，可下載或長按存圖。

卡片主打的是**坐向**（你家坐什麼朝什麼、大門正對哪一顆流年星），不是「財位在哪」——
因為 2026 的飛星八方位是絕對方位，每個人的財位都在東，拿那個當結果卡沒有個人化、也沒人想轉。
角度落在山界 ±1.5° 內時，卡片上會跟工具一樣印出壓線警告（工具會警告、卡片不警告，等於對外少講一句）。

圖不上傳、不經過任何伺服器，全在使用者瀏覽器裡畫完。

## 演算法（都是查表，不含隨機）

**24 山**：360° 切 24 等分，每山 15°，子山中心對正北 0°（子＝352.5°–7.5°），
順序 子癸丑艮寅甲卯乙辰巽巳丙午丁未坤申庚酉辛戌乾亥壬。
圖上定出來的角度是「向」，「坐」＝向 +180°。

**2026 流年飛星**：年紫白＝ 11 −（西元年數字和化到個位）。
2026 → 2+0+2+6 = 10 → 1；11 − 1 = 10 → **一白入中宮**，依洛書順飛
（中 → 乾 → 兌 → 艮 → 離 → 坎 → 坤 → 震 → 巽）：

| 方位 | 角度 | 星 | 標籤 |
|---|---|---|---|
| 北 | 337.5°–22.5° | 六白武曲 | 貴人 |
| 東北 | 22.5°–67.5° | 四綠文曲 | **文昌** |
| 東 | 67.5°–112.5° | 八白左輔 | **財庫** |
| 東南 | 112.5°–157.5° | 九紫右弼 | **喜慶** |
| 南 | 157.5°–202.5° | 五黃廉貞 | **忌動工** |
| 西南 | 202.5°–247.5° | 七赤破軍 | **破財** |
| 西 | 247.5°–292.5° | 三碧祿存 | 是非 |
| 西北 | 292.5°–337.5° | 二黑巨門 | 病符 |
| 中宮 | — | 一白貪狼 | 桃花 |

八方位是**絕對方位**（真北為準），與建築轉幾度無關；坐向決定格局，方位決定今年動哪裡。

## 已知限制（實測結果，不要美化）

- **台灣門牌在 OpenStreetMap 上查不到。** 實測 Nominatim：
  `台北市信義區市府路1號` → 0 筆且要跑 10.7 秒才回；`信義區市府路` → 5 筆、95ms。
  所以搜尋做了降級鏈（去門牌 → 去縣市 → 去巷弄 → 台/臺 互換），
  帶「號」的原字串**直接跳過不打**，避免十秒空等。搜尋只負責帶到路段，最後一哩由使用者拖點。
- **國土測繪影像在極低縮放（z<13 左右）會回近乎空白的圖磚**，底下墊了一層 OSM 但會被蓋住。
  預設起始 zoom 為 19，實務上不會遇到。
- **兩點對齊的「向」有 180° 歧義**：程式取「背離屋頂中心」的那一側當作向，
  並要求使用者用地圖上的紅箭頭目視確認（指到屋內就按翻轉）。這是刻意保留的人工確認點。
- 定位鈕需要 HTTPS 與使用者授權，失敗時會提示改用地址搜尋。
